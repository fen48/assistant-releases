# Ассистент — обновления

Подписанные пакеты обновлений корпоративного мессенджера «Ассистент».
Серверы компании проверяют папку `updates/` раз в час и раздают новые версии программам сотрудников по локальной сети.

- `updates/latest-*.json` — описание последней версии (подписано ключом издателя Ed25519)
- `updates/assistant-*.asb` — пакеты обновлений сервера, программы сотрудников и консоли администратора

Файлы без верной подписи программы не устанавливают. Выпуск новой версии: `node publish.js 1.2.0 "Что нового" --push путь/к/assistant-releases`.
